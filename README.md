# SamAI v1 — اتاق فکر خودکار کامنت اینستاگرام

برنامهٔ محلی برای کشف رسانه و کامنت، ساخت پاسخ در دو مرحلهٔ Gemini، نقد مستقل، ثبت تاریخچه در SQLite و انتشار اختیاری از مسیر رسمی Instagram Graph API. داشبورد به‌صورت پیش‌فرض فقط روی `127.0.0.1` اجرا می‌شود.

## شروع

۱. محیط مجازی و `.env` موجود پروژه را نگه دارید. فایل `.env.example` فقط نمونهٔ متغیرهاست و اعتبارنامهٔ واقعی ندارد.

۲. در PowerShell:

```powershell
cd C:\Users\Jafar\Downloads\SamAI
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py"
```

۳. برنامه را با `start_samai.bat` اجرا کنید یا:

```powershell
.\.venv\Scripts\python.exe -m uvicorn dashboard:app --host 127.0.0.1 --port 8000
```

داشبورد: <http://127.0.0.1:8000>

## حالت آزمایشی و انتشار

انتشار واقعی به‌صورت پیش‌فرض خاموش است. ابتدا داشبورد را باز کنید، «اجرای یک چرخه» را بزنید و پیش‌نویس‌ها و خطاهای اتصال/مجوز را بررسی کنید. برای اجرای مداوم، «شروع کارگر» را بزنید.

برای فعال‌سازی خودکار در داشبورد، تیک «حالت آزمایشی» را بردارید، تیک «فعال‌سازی انتشار خودکار در تولید» را بزنید و تنظیمات را ذخیره کنید. هر دو مقدار `DRY_RUN=false` و `AUTO_PUBLISH=true` لازم‌اند؛ داشبورد این دو را هم‌زمان تنظیم می‌کند. سپس کارگر را اجرا کنید. کلید مکث سراسری و توقف اضطراری فوراً جلوی پردازش و انتشار بیشتر را می‌گیرند.

Meta مستند می‌کند که پاسخ مستقیم از `POST /{ig-comment-id}/replies` انجام می‌شود و توکن/مجوزهای `instagram_basic`, `instagram_manage_comments`, `pages_show_list`, `page_read_engagement` لازم است؛ در برخی نقش‌های Business Manager مجوز تبلیغاتی دیگری هم لازم می‌شود. خطای دسترسی در تاریخچه به‌صورت خلاصه ثبت می‌شود. حساب باید واجد شرایط API و توکن دارای مجوز باشد.

۱۹ شناسهٔ `comments.json` برای رگرسیون محلی نگه داشته شده‌اند و برای همیشه از انتشار خودکار مستثنا هستند. هیچ دادهٔ تاریخچه‌ای از فایل `generated_replies.json` به صف انتشار منتقل نمی‌شود.

## هزینه، حریم خصوصی و عملیات

- مدل روی `gemini-3.5-flash-lite` ثابت است و fallback به مدل پولی ندارد. اگر مدل یا سهمیه در دسترس نباشد، کار متوقف/برای تلاش محدود بعدی نگه داشته می‌شود.
- سقف درخواست/توکن/انتشار و تعداد کامنت هر چرخه در `.env.example` قابل تنظیم‌اند؛ quota واقعی حساب Gemini را از AI Studio بررسی کنید.
- برای نزدیک‌شدن به سقف زمینهٔ مدل، هر دسته علاوه بر تعداد کامنت با بودجهٔ اندازهٔ ورودی (`MAX_BATCH_CHARS`) هم تقسیم می‌شود.
- پردازش کامنت از نیمه‌شب محلی برلین در اولین اجرای برنامه آغاز می‌شود؛ تاریخ شروع در SQLite ثابت می‌ماند. فقط کامنت‌هایی با timestamp معتبر اینستاگرام از آن تاریخ به بعد وارد صف می‌شوند. تاریخ‌های داشبورد با تقویم میلادی و منطقهٔ زمانی برلین نمایش داده می‌شوند.
- کپشن و متن کامنت به‌عنوان ورودی غیرقابل‌اعتماد به Gemini داده می‌شوند؛ نام کاربری ارسال و در SQLite ذخیره نمی‌شود.
- دیتابیس محلی `samai.sqlite3` است. نگهداری پیش‌فرض ۱۸۰ روز است. برای پاک‌کردن همهٔ تاریخچه، برنامه را متوقف و دیتابیس را حذف کنید.
- راستی‌آزمایی بیرونی به‌طور پیش‌فرض غیرفعال است؛ سیستم منبع یا استناد ساختگی تولید نمی‌کند.
- تنظیم‌های داشبورد در SQLite ماندگارند؛ متن شخصیت و دستورالعمل در `prompts/` ذخیره می‌شود.
- درخواست انتشار Graph API بدون retry خودکار فرستاده می‌شود. اگر پاسخ مبهم یا برنامه متوقف شود، پیش از هر تلاش بعدی پاسخ‌های موجود از اینستاگرام خوانده می‌شوند.

## ساختار

`instagram_api.py` اتصال Meta، `think_tank.py` دو مرحلهٔ Gemini، `worker.py` صف و زمان‌بندی، `database.py` حافظه، `dashboard.py` API وب، `fact_checker.py` رابط بررسی واقعیت، `prompts/` شخصیت و نقش‌ها و `tests/` آزمون‌های آفلاین را فراهم می‌کنند.
